# BELENTANI / 20 WORLDS

Workspace web aislado para BELENTANI.

## Uso

```powershell
bun install
bun run dev
```

## Verificacion

```powershell
bun run typecheck
bun run lint
bun run test
bun run build
```

## Estructura

- `src/` codigo de aplicacion
- `server/` API
- `public/` assets y entrada web
- `tests/` verificacion
